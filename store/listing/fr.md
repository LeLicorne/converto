## Description

Converto convertit vos fichiers directement sur votre téléphone. Rien n'est envoyé, rien n'est suivi.

COMMENT ÇA MARCHE
1. Choisissez un fichier. Le format est détecté automatiquement.
2. Choisissez le format voulu. Seules les conversions possibles sont proposées.
3. Réglez les options si vous le souhaitez, puis lancez la conversion.
4. Enregistrez, partagez ou ouvrez le résultat.

CE QUE VOUS POUVEZ CONVERTIR
• Images : JPG, PNG, WebP, HEIC, AVIF, GIF, BMP, TIFF, et image vers PDF
• PDF : vers images (une par page ou une seule image continue), vers texte, fusion, extraction de pages, rotation
• Documents : Markdown, HTML, texte et DOCX vers PDF ou texte
• Données : CSV, JSON et XLSX dans tous les sens
• Audio : MP3, AAC, M4A, WAV, FLAC, OGG, Opus, AIFF
• Vidéo : MP4, MOV, MKV, WebM, GIF animé, ou extraction de l'audio
• Archives : création et extraction de ZIP

CONFIDENTIEL PAR CONCEPTION
• Fonctionne entièrement hors ligne
• Sans publicité, sans compte, sans suivi, sans cookies
• Gratuit, sans achat intégré
• Vos fichiers ne quittent jamais votre appareil

ACCESSIBLE
Compatible lecteurs d'écran, taille de texte réglable, thèmes clair et sombre. Disponible en français, anglais, espagnol, allemand, italien, portugais et néerlandais.
