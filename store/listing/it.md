## Description

Converto converte i tuoi file direttamente sul telefono. Nulla viene caricato, nulla viene tracciato.

COME FUNZIONA
1. Scegli un file. Il formato viene rilevato automaticamente.
2. Scegli il formato desiderato. Vengono proposte solo conversioni possibili.
3. Regola le opzioni se vuoi, poi converti.
4. Salva, condividi o apri il risultato.

COSA PUOI CONVERTIRE
• Immagini: JPG, PNG, WebP, HEIC, AVIF, GIF, BMP, TIFF e immagine in PDF
• PDF: in immagini (una per pagina o una sola immagine lunga), in testo, unione, estrazione di pagine, rotazione
• Documenti: Markdown, HTML, testo e DOCX in PDF o testo
• Dati: CSV, JSON e XLSX in ogni direzione
• Audio: MP3, AAC, M4A, WAV, FLAC, OGG, Opus, AIFF
• Video: MP4, MOV, MKV, WebM, GIF animata o estrazione dell'audio
• Archivi: creazione ed estrazione di ZIP

PRIVATA PER DESIGN
• Funziona completamente offline
• Niente pubblicità, account, tracciamento o cookie
• Gratuita, senza acquisti in-app
• I tuoi file non lasciano mai il dispositivo

ACCESSIBILE
Supporto per lettori di schermo, dimensione del testo regolabile, temi chiaro e scuro. Disponibile in italiano, inglese, francese, spagnolo, tedesco, portoghese e olandese.
