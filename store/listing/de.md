## Description

Converto konvertiert deine Dateien direkt auf deinem Telefon. Nichts wird hochgeladen, nichts wird verfolgt.

SO FUNKTIONIERT'S
1. Wähle eine Datei. Das Format wird automatisch erkannt.
2. Wähle das gewünschte Format. Es werden nur sinnvolle Konvertierungen angeboten.
3. Passe bei Bedarf die Optionen an und konvertiere.
4. Speichere, teile oder öffne das Ergebnis.

WAS DU KONVERTIEREN KANNST
• Bilder: JPG, PNG, WebP, HEIC, AVIF, GIF, BMP, TIFF sowie Bild zu PDF
• PDF: zu Bildern (eines pro Seite oder ein langes Bild), zu Text, zusammenführen, Seiten extrahieren, drehen
• Dokumente: Markdown, HTML, Text und DOCX zu PDF oder Text
• Daten: CSV, JSON und XLSX in jede Richtung
• Audio: MP3, AAC, M4A, WAV, FLAC, OGG, Opus, AIFF
• Video: MP4, MOV, MKV, WebM, animiertes GIF oder nur die Tonspur
• Archive: ZIP erstellen und entpacken

PRIVAT VON GRUND AUF
• Funktioniert komplett offline
• Keine Werbung, kein Konto, kein Tracking, keine Cookies
• Kostenlos, ohne In-App-Käufe
• Deine Dateien verlassen nie dein Gerät

BARRIEREFREI
Screenreader-Unterstützung, einstellbare Schriftgröße, helles und dunkles Design. Verfügbar auf Deutsch, Englisch, Französisch, Spanisch, Italienisch, Portugiesisch und Niederländisch.
